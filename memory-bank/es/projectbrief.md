# Banco de Memoria Geek_Shop — Resumen del Proyecto

Propósito
- Proporcionar una línea base de documentación viva que describa el alcance, objetivos y decisiones del proyecto.
- Servir como la fuente de verdad para la planificación y el progreso entre sesiones.

Alcance
- Frontend: tienda (catálogo, detalles del producto, carrito, checkout, cuenta de usuario) con React y TypeScript.
- Arquitectura: interfaz basada en componentes, clara separación de responsabilidades y patrones documentados.
- Configuración de desarrollo: desarrollo local con herramientas comunes (Vite, TS, ESLint/Prettier).
- Documentación: archivos del banco de memoria que evolucionan con el proyecto.

Objetivos
- Mantener una dirección de producto clara y un historial de decisiones.
- Garantizar la retención de memoria entre sesiones actualizando los archivos centrales de contexto.
- Habilitar mejoras incrementales con trazabilidad.

Criterios de éxito clave
- Los archivos centrales del memory bank existen y están actualizados.
- ActiveContext y Progress capturan el estado actual y los próximos pasos.
- SystemPatterns y TechContext documentan decisiones de arquitectura y restricciones tecnológicas.

Restricciones y Supuestos
- Todos los archivos del memory bank son Markdown y se encuentran bajo memory-bank/.
- Las actualizaciones ocurren tras cambios significativos o por solicitudes explícitas para actualizar el memory bank.
- El Banco de Memoria es la referencia principal para la planificación en tareas siguientes.
