# Banco de Memoria Geek_Shop — Contexto del Producto

Por qué existe este proyecto
- Proporcionar una línea base de documentación viva que describa el propósito, los objetivos y las decisiones del producto.
- Establecer un modelo mental compartido para las partes interesadas y futuros colaboradores.
- Servir como la fuente de verdad principal para la planificación entre sesiones.

Problemas que soluciona
- Comprensión fragmentada del propósito del producto y de las necesidades del usuario.
- Falta de una referencia centralizada para decisiones arquitectónicas y restricciones tecnológicas.
- Dificultad para incorporar nuevos colaboradores debido a la falta de contexto documentado.

Cómo debería funcionar
- Alinear el razonamiento del producto, los problemas de los usuarios y la experiencia prevista.
- Documentar características de alto nivel y flujos sin imponer detalles de implementación.
- Mantenerse ligero y evolucionar a medida que el proyecto crezca, siempre haciendo referencia al projectbrief para el alcance.

Metas de experiencia de usuario
- Navegación clara e intuitiva y rápida interacción con catálogo, carrito y checkout.
- Patrones UI/UX consistentes entre páginas, accesibles y adaptables.
- Comunicación transparente de cambios de estado y retroalimentación a los usuarios.

Secciones clave
- Propósito y metas del producto
- Usuarios objetivo y casos de uso
- Visión general de características de alto nivel
- Consideraciones UX y criterios de éxito
- Dependencias e puntos de integración con systemPatterns y techContext
